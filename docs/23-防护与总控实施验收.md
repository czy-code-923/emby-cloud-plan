# 23 防护、总控与回归验收（v6.0）

本轮只有文档/配置/离线模型/界面原型检查；以下真实请求、网络压力和宿主操作尚未执行。不得对他人服务器或真实网盘进行无授权攻击演练；测试使用隔离环境、测试账号/条目和受控模拟上游，先设速率/时长/流量停止阈值。

## 1. 正常客户端基线

每个固定版本客户端记录登录、首页海报、电影/多季剧/特别篇、搜索/分页、直接播放、302、HEAD/Range、拖动、重播、换字幕/音轨、暂停恢复、断线重连、签名过期、HLS/DASH分片与心跳。测试电视/手机/浏览器及同一NAT多人、移动网络换IP。

通过条件：路由分类可解释，同一会话不重复占同播/有效分钟；合法请求没有被全站低频规则误伤；缺海报/片源失效不被当作恶意ID扫描；真实拒绝/延迟与无防护基线对比有记录。不能以一个浏览器能播代替全部客户端覆盖。

## 2. 隔离攻击/故障矩阵

| 场景 | 要验证的结果 |
|---|---|
| 未登录遍历库/随机ID/原端口/管理API | 没有拿到库/用户/路径/直链或管理能力；登录必需最小发现仍可用 |
| 有效账号读他库/图片/字幕/下载 | 对象权限在所有别名路径生效，不泄露权限外条目 |
| 同UID多设备/换IP/改query遍历 | 共享UID预算，UA/客户端PlaySessionId不能重置预算；家庭IP不被永久连坐 |
| 一毫秒100次同剧集控制请求 | 在模型假设下1签发/19复用/80限流；真实网关验证不多占租约/调用上游，不无限等待 |
| 10次合法短时重试/seek/分片 | 正确复用，不按每段新开播；限制数据请求不把所有视频断流 |
| 多条目快速索取直链/大分页/多筛选 | 原子窗口、条目/签发预算先观察再执行；超额不触发网盘高成本请求 |
| 两UID点同片/两规格/新来源/撤销epoch | 权限隔离缓存；撤销后即便有缓存不发新授权，不能跨用户复用用户响应 |
| 超长参数/体积、慢头体、巨图/解压炸弹 | 尺寸/时间/像素边界阻断，视频长流采用独立读空闲超时 |
| 伪造Forwarded/Host、IPv6绕源、SSRF | 可信代理和域白名单有效，网盘/备份目的地不能访问未授权内网/云元数据 |
| 撞密码/安全码/码、TG回调风暴/重放 | 分组限流/短冷却/事务幂等；不扣多次、不永久封真实账户 |
| 风控缓存耗尽/计数器重启/双进程 | 内存/键有上限，不因抖动无限放行签发；多执行者不各给完整额度 |
| 网盘429/超时/DB故障 | 播放优先、有限重试/在途、拒绝新高成本、旧合法会话有限降级 |
| 单节点网络带宽被打满 | 本机告警/暂停后台与上游处置路径明确；不能宣称应用限流已挡大DDoS |
| 规则误报/申诉/临时白名单到期 | 能撤限、规则回滚和看原因；不删除用户、积分或已付权益 |

## 3. 可视化总控验收

角色矩阵：Support不能发码/改分/改域，Finance不能读取网盘secret，ContentEditor不能发布强制封禁，安全操作员不能改收款人。Owner也需版本/原因/危险确认，不能绕过资金事实。

草稿不改变线上值；跨管理员同版本保存产生409并保留输入；错误字段/超限/缺依赖可定位；修改令牌后前端不回显secret；配置应用失败显示desired/applied差异，回滚只改配置版本、不恢复旧业务账本。

前端/网关/执行器逐层校验请求scope；绕过UI直接调API、篡改operation_id/目标实例/路径/价格/角色均失败。部署操作不能运行任意shell；来源失联也不能把所有应用标成功。

移动320/360和桌面768/1440检查所有导航、长字段、键盘焦点、错误态、确认弹窗、发布后回执与取消，不溢出/遮挡。关闭所有外部接口后面板仍能经受控管理通道恢复；避免锁死唯一管理员入口。

## 4. 购买外链的验收边界

普通URL按钮技术上可实现，但平台状态不满足时草稿不能发布；不因改名“发电”展示现金目录或突破规则Gate。目的地只接受验证过的HTTPS域，禁止任意跳转/敏感query/恶意Unicode域；公开配置不泄露域名草稿或身份。

当前默认无外链、TG付费码生产关闭、独立网站人工告知/核销继续。以后若有明确适用依据，更新有日期的审核记录和已应用策略，再测按钮/旧菜单缓存/关闭；不把本轮模拟页面点击当外链获准或已部署。

## 5. 上线与扩大规模门槛

先通过鉴权/对象权限/原端口隔离→收集72小时行为基线→样例回放与误伤评审→仅新会话小范围执行→确认来源签发次数下降、资源/投诉不过阈值→再开放更多用户。临时规则有自动到期，外部DDoS服务另确认实际能力/价格/流量路径，不在设计里写无限防护。

交付记录应包含组件/客户端/路由profile版本、测试身份、每场景样例与期望/实际、拒绝原因、实际网盘调用、CPU/RAM/带宽峰值、延迟/错误、恢复时长和残余风险。测试失败先保持观察或停售相关保证，不把“有防火墙”当所有项目通过。

`scripts/verify_anti_abuse_model.py`只验证计数/合并键/权限顺序的离线契约，结果在`analysis/anti-abuse-model.json`；不启动服务、不发网络请求，也不能证明真实原子并发或抵抗攻击。实际实现测试应以这里的用户行为和故障结果为依据，不只断言某函数返回true。
