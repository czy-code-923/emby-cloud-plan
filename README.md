# 个人云盘 Emby 与 Telegram 服务完整方案

版本：7 · 更新日期：2026-11-19 · 状态：设计与交互原型，尚未部署、实机压测或完成安全验收。

以现有 **美西 2核2GB VPS＋网盘**起步，先跑通直播放、自动整理刮削、增量更新和 Telegram 自助服务。注册支持开放、邀请、购买及其组合；后续升级服务器时沿用同一套用户和权益模型。

本仓库存放方案、规则示例和验收清单。配置示例是拟开发系统的设计输入，不是已经实现的软件配置。真实域名、密钥、网盘凭据和用户数据不应提交。

**最终方案入口：[27篇完整合订本](docs/完整方案.md)；快速通读最终架构、规则与遗漏闭环见[第27篇](docs/27-最终方案与遗漏闭环验收.md)。**

**TG面板与网页总控是两个独立界面。**TG面板面向用户自助，可选管理员快捷摘要；网页总控通过浏览器直接访问`admin.example.com`（示例），独立管理员登录＋MFA，统一管理所有项目设置，包括TG本身。无需先打开Telegram或依赖Bot登录；两者复用业务后端事实，分别使用权限/API入口和会话。独立购买网站另作为第三个入口，见第22篇的职责表。

## 推荐决策

1. 单机 Docker Compose；Emby＋一个已验证网盘适配器＋CloudBot/控制器＋PostgreSQL＋Caddy。初期不强制部署 Redis、Sonarr、Radarr、CloudDrive2 或监控全家桶。
2. 当前优先OpenStrm＋有效内网取源映射，缺少现成映射时验证内网OpenList并计入内存；Emby负责自动刮削。115为验证候选，其他网盘逐个测试，不能把能挂载当成能302。
3. 参考Twilight、MoviePilot、Wizarr与Seerr，优先验证复用Twilight作为唯一用户业务底座，定制规则在同一服务扩展；不并行另一套会改余额/到期的用户中心。
4. 免费用户选择**签到积分保号或观影保号**，每20天一个选择/考核窗口，可预约下期切换；按所选模式考核，不随时重置周期。
5. 积分兑换和购买在活动之上：月/季/年卡有效期内**免签到、免观影**。积分价提案300分/30天、850分/90天、3000分/365天，均可调整；签到活动分与钱包分离。
6. 302 场景可以控制新播放授权、识别常规客户端和统计上报会话；不能承诺绝对设备防伪、精确 CDN 字节计量或立刻收回已签发直链。
7. 核验后采用无购买外链的分离方案：独立网址由运营者手动告知，网页完成商品/付款/核款/发码；Bot及Mini App不显示购买按钮、商店网址、现金价或付款入口。TG保留免费积分、账户/权益及码核销；月/年码核销起算时长。官方未明确豁免付费码组合，不能宣称去掉外链就必然合规，依据和边界见第16篇及核验报告。
8. TG原生菜单＋Mini App面板，独立安全码/恢复码，管理员单用户积分与权益覆盖，后端统一鉴权与审计。
9. 自由设置全服/节点/网盘/用户的资源、人数与总同播。系统识别VPS给有证据的建议，不自动扩大售卖容量。
10. 备份验证、隔离恢复、跨VPS/业务中心/网盘迁移具有预检、对账与回滚。
11. 每日钱包签到改为10～20分整数等概率，平均15分；月卡300分，从零余额平均20.4889次签到，22次达标概率98.0433%，30次保证足够。本期活动分仍固定10分/日，不被随机运气影响。
12. 媒体采用唯一任务调度、唯一元数据所有者、唯一Bot收件者；复杂来源路线再评估MoviePilot，AutoFilm＋MediaWarp作为替代组合，避免重复组件相互覆盖。
13. 月/年注册、续期、限期白名单支持独立份额、活动价和手动关闭；已售未兑码计入承诺容量，下架不取消已售交付责任。
14. 用户帮助、公告和客户端清单由后台版本化编辑；使用说明与实际客户端拦截分开。游戏积分、异地备份留独立最小权限接口，默认关闭，关闭时阻止在途旧授权继续执行。
15. 域名分用途验证绑定、证书与配置分阶段发布；媒体/账户/商店裸IP访问默认分别关闭，管理仍用VPN/隧道与MFA。全套安全边界与待实施用例见第20篇。
16. 新增分层防扫库/防连点：对象权限、分页/搜索/不同条目预算、重复控制请求合并、有限在途与来源签发；Range/分片/心跳单独分类，避免误伤。行为规则先观察72小时，鉴权/尺寸/原端口隔离始终执行；不承诺绝对防爬或靠本机抵御大DDoS。
17. 独立可视化总控覆盖24个模块，包含配置schema、草稿/影响预览、MFA/版本确认、受限执行器、desired/applied状态和回滚；新增可点击后台原型，不表示后端已实现。
18. 新请求的TG“发电”外链在技术上可做，已加入总控草稿/发布Gate；2026-11-18官方复核仍未确认豁免，生产有效开关保持关闭、独立网站方案继续。交付注册码/续期/白名单不因改称发电变成无对价捐赠，见第24篇。
19. 总控24模块覆盖此前全部功能/设置：收款完整工作台、备份恢复/迁移、通知中心、凭据/任务/隐私均有独立入口，所有13份示例配置字段登记归属，未实现能力明确标注。
20. 新增更新助手：未来可信程序仓库自动检查/验证拉取、预检/备份/维护应用/健康验收与兼容回退；支持自动下载后手动应用或限定维护窗口自动应用。程序仓库尚未创建，当前未配置/不执行，现有方案仓库不作程序源。

## 已确认与尚待确认

- 已确认：美西2核2GB，未来可能升级；三种注册；活动方式每20天可重选；兑换/购买有效期间免保号。
- 新确认需求：网页商店默认口令红包、可选收款码、人工核款后单次码发货；帮助/公告可编辑、商品份额/促销、游戏积分扩展、外端备份接口、域名/IP开关。
- 原方案提到 30GB 磁盘，本次未确认实际剩余空间；VPS 月流量、网盘、Emby 版本、域名、用户规模均待填。
- 默认设计：邀请制启用、开放注册和购买注册可在后台开启；免费保号规则为提案，可配置，不是已经生效的服务条款。
- 本轮确认：独立网页总控管理上文所有设置（含备份/收款），新增未来程序仓库更新助手；程序仓库未创建，仅做方案。
- 未执行：VPS 部署、网盘授权、支付开通、真实用户操作与实际播放测试。

方案中所有内存、延迟、并发和调度值都是起始预算或验收目标，不能视为当前服务器测试结论。第三方能力核验与来源见[参考说明](docs/07-资料核验与待定参数.md)。
