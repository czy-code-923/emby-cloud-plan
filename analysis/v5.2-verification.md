# v5.2 无购买外链方案核验

日期2026-11-13。当前版本采用用户授权的备选：独立商店网址人工告知，Bot/Mini App不提供购买链接或现金销售界面。官方事实与不确定性见[规则核验](telegram-commerce-review-2026-11-13.md)。

本地核验：

- README、交易/机器人/UI/内容/实施/安全篇及配置同步；20篇合订本重新生成，8份YAML可解析。
- 购买URL为null、设计开关false；Stars/第三方现金结账关闭；现金目录/完整订单链接不返回TG受众。付费码TG生产开关默认关闭，免费/管理员码分开控制；用户现金订单通知只在网页，管理员私密待办单独配置。
- 原型删除购买按钮及其处理分支；TG五个用户页、帮助和码状态页无现金价格、渠道/收款材料或购买网址。
- Chrome独立headless会话在320/360/768/1440px验证：签到积分兑换仍可用；设计预览器独立切到网页→人工核准演示→发码→TG付费来源演示被禁→网页一次核销→TG显示权益。没有横向溢出、JS异常或外部HTTP/HTTPS请求。
- 检查360px深色TG兑换页，确认无购买按钮且内容可读。预览器切换不是实际Bot导航/跳转。
- 本地链接、代码块、Git空白、常见凭据模式及原始v1/合订本导出一致性检查。

这些只验证设计和静态演示，不证明后端鉴权/码来源校验/平台豁免，也不是实际收款/网页上线或VPS部署。没有向用户发送独立网址，没有向Telegram提交个案询问；真实付费码能否在TG核销仍须平台适用确认，移除外链不自动解决此问题。
